## 起動

このフォルダをターミナルで開き、次を実行する。

```sh
python -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開く。`file://` の直接表示ではJSONを取得できない。ビルド・npm・DB・ログイン・APIキーは不要。

## 動作

- 展示本文は最初から読める。入力フォームは登録名・正式展示名・公式URLに一致したとき本文へ移動する。
- 名前はNFKC正規化・空白統一。URLはHTTPSのホスト（ポートを含む）とパスで照合し、末尾スラッシュ・クエリ・フラグメントを吸収。似たドメインや未知のパスを受け入れない。
- 未登録の入力には「まだ予習ページを用意していません」と、登録展示へのリンクだけを表示する。任意URLの取得やAI生成は行わない。
- 「5分予習／人物と時代／作品／会場／深掘り」のアンカーと、会場へ移動するボタンを用意。
- 会期は端末の時計から`Asia/Tokyo`で年月日を求める。開催前／前期／展示替え／後期／会期終了の5状態。開館状況とは別。ページを開く／再読み込みする時点で判定する。
- 前期は3カード、後期は通期の絵巻だけを表示し、公式リストへ誘導。展示替え・終了時は鑑賞予定と誤認しないよう会場カードを非表示にし、記事と出典を残す。
- JSONの文字列は`textContent`で描画。外部リンクは資格情報のないHTTPS URLに限定し、`noopener noreferrer`を指定。
- JSON読込失敗時は再読み込みの案内と公式リンクを残す。

原仕様ではPublic Domain表示を2026-10-01に確認済み。この実装では画像を取得した／再検証したとは扱わない。[Met Open Access](https://www.metmuseum.org/hubs/open-access)と実際に取得する画像の利用条件を再確認する。

画像を追加するとき：

1. 利用条件を確認してダウンロードし、最適化した実ファイルを`assets/`配下へ置く。外部ホットリンクは使わない。
2. `knowledge.json`の対象作品に`localImagePath`（例：`assets/met-45434.webp`）、実ファイルの`width`と`height`を入れ、`alt`・年代・権利確認日を確定する。
3. 観察する箇所を選び、別の部分画像を作る。`detailImagePath`、`detailWidth`、`detailHeight`、`detailAlt`を入れる。表示上も「部分拡大」とする。
4. 全体はcontain表示し、タップで別タブに開く。冒頭以外は遅延読み込み。画像が読めなくてもプレースホルダー・解説・作品情報リンクを残す。

## 実装に必要な残作業

- Metの2画像の取得、年代・実寸・利用条件の最終確認、表示用と部分画像の最適化。これが終わるまで「画像付き予習の完成」にはしない。
- 画像を見ながら実際に約5分読めるか確認し、本文量を調整。現在は原仕様の初稿を移した状態。
- 公開直前に公式の展示替え・開館・出品情報とリンクを再確認。後期の新たな2作品の原稿は未作成のため、現在は公式リストへ誘導する。
- 375px幅とPC幅で実ブラウザの表示を確認。この実行環境にはブラウザ実体がなく、追加取得もできなかったため、見た目・横スクロール・スクロール位置の実測は未実施。375px向けの1列CSSとアンカーの接続は実装済み。
